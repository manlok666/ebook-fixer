# ebook-fixer

中文译本 EPUB 可读性修复工具。外国书籍的中文译本（尤其欧洲文学）常整页只有一两个超长段落、对话混在叙述里，黑压压难以读下去。本工具在浏览器内对 EPUB 自动做「拆段、对话独立、首句锚点、排版注入」，预览满意后导出修复版 EPUB。

**所有处理都在浏览器本地完成，电子书文件不会上传到任何服务器。**

## 功能

| 规则 | 说明 | 自定义控件 |
| --- | --- | --- |
| 长段智能拆分 | 超过阈值的段落在句末标点处拆分，优先拆在场景词（这时/第二天/后来…）或转折词（但/然而/不过…）之后 | 阈值滑杆（100–400 字，默认 200） |
| 对话独立成段 | 直角引号「」『』的对话（含相邻提示语「他问道」）独立成段，还原西文原著的对话排版；双引号（“”）仅用于术语强调，不作拆段依据 | 开关 |
| 首句锚点 | 长段落首句加粗或浅色高亮，扫读时有视觉抓手 | 三档：加粗 / 高亮 / 关闭 |
| 阅读排版注入 | 行距、段间距、每行字数（25–35 汉字）、首行缩进，纯 CSS 注入不改文字 | 行距 / 段距 / 行长滑杆、缩进选择 |
| 场景分隔符 | 星号行等场景切换统一为居中 `◇　◇　◇` | 开关 |
| 标点规范化 | 省略号（……）、破折号（——）、直引号统一为弯引号（直角引号保留） | 开关 |

预览与导出：

- **对照预览**：原文 / 处理后左右对照，改动处字符级高亮
- **阅读模式**：epub.js 仿真阅读器，模拟真实阅读器效果
- **导出**：一键下载修复后的 EPUB，保留原书其余内容不动

## 技术栈

- **前端框架**：Vue 3（Composition API + `<script setup>`）+ Vite 6 + TypeScript
- **EPUB 处理**：JSZip（解包/重打包）+ DOMParser / XMLSerializer（XHTML 改写），纯浏览器端规则引擎
- **阅读预览**：epub.js（按需加载）
- **差异对照**：jsdiff（段落对齐 + 字符级高亮）
- **测试**：Vitest + jsdom（现场构造最小 EPUB 做规则与 round-trip 断言）

## 快速开始

要求 Node.js ≥ 20（建议 24）。

```bash
# 安装依赖
npm install

# 启动开发服务器（默认 http://localhost:5173）
npm run dev

# 构建静态产物（输出到 dist/，可直接部署）
npm run build

# 预览构建产物
npm run preview
```

## 测试与类型检查

```bash
# 运行单元测试（27 个用例：规则引擎 / EPUB round-trip / diff）
npm test

# TypeScript 类型检查
npm run typecheck
```

## 使用方法

1. 打开页面，拖入或选择 `.epub` 文件
2. 左侧调整修复规则，右侧实时查看对照预览
3. 切换「阅读模式」检查真实阅读效果
4. 点击右上角「导出 EPUB」下载修复版

## 项目结构

```
src/
  engine/          # 纯 TS 规则引擎 + EPUB IO（零 Vue 依赖，可单测）
    epub/          #   解包 / XHTML 解析容错 / 重打包
    rules/         #   六条规则各一文件
    text/          #   分句、引号状态机
  composables/     # 状态管理（useProject / useSettings / usePreview）
  components/      # UI 组件（上传、规则面板、对照预览、阅读器…）
tests/             # Vitest 单测（JSZip 现场构造最小 EPUB）
```
